# BtBattery

> 一个约 0.91 MB 的 Windows 托盘小工具，帮你盯着蓝牙耳机、鼠标、键盘的剩余电量。
> 免安装、不联网、 双击就能用。

BtBattery 常驻任务栏右下角，读的是 Windows 自己写进设备属性里的电量值
（`DEVPKEY_BLUETOOTH_BATTERY`），所以数字和「设置 → 蓝牙和其他设备」里显示的
一模一样：**系统页面上有，这里就有；系统页面上没有，这里就如实显示「不支持」**，

## 特性

- **与系统同源** —— 电量来源就是 Windows 写入设备属性的那个值，和系统设置页一致。
- **经典蓝牙也读得到** —— 不止 BLE，头戴式蓝牙耳机这类经典蓝牙设备同样能读到。
- **低电量分档提醒** —— 跌破阈值（默认 20%）提醒一次，之后每再降 10 个百分点再提醒一次。
- **图标颜色即电量** —— 托盘图标按「最低的那台设备」填充：40% 以上绿色，跌破 40% 立刻变红。
- **蓝牙关闭单独提示** —— 适配器被禁用时菜单顶部单独提醒，免得把「设备同时离线」误判成设备坏了。
- **免安装、可诊断** —— 绿色单文件，配置与日志跟着 exe 走；`--diag` 一条命令导出全部设备节点。

认得出的设备类型：头戴耳机、入耳耳机、蓝牙鼠标、蓝牙键盘、游戏手柄、蓝牙音箱。

## 快速开始

1. **下载 · 双击** —— 免安装，也不需要 .NET 运行时。第一次运行，任务栏右下角会出现一个电池小图标。
2. **右键看电量** —— 右键托盘图标，菜单里列出每台已配对设备的电量与类型；鼠标悬停图标也能看到最近读数。
3. **用完就删** —— 想卸载直接删掉 exe 即可，`settings.json` 和 `logs\` 就在 exe 旁边，一起删掉，系统里不留残余。

## 命令行

| 参数 | 作用 |
|---|---|
| `--diag` | 打印全部蓝牙设备节点与电量读取结果后退出（不进托盘、不占用单实例锁），读不到电量时用来排查 |
| `--selftest` | 跑内置的纯函数回归测试，按结果返回退出码（0 = 全过），同样不进托盘 |

## 从源码构建

需要 **.NET 8 SDK**（含 Native AOT 工具链）。Windows 上还需要安装 Visual Studio 的
「使用 C++ 的桌面开发」工作负载，以提供 MSVC 原生链接工具链。

```powershell
# win-x64
dotnet publish src/BtBattery/BtBattery.csproj -c Release -r win-x64 -p:DebugType=none

# win-arm64（AOT 交叉编译需要装有 ARM64 版 MSVC 工具链的机器）
dotnet publish src/BtBattery/BtBattery.csproj -c Release -r win-arm64 -p:DebugType=none
```

## 技术说明

- **.NET 8 + Native AOT**，单文件 exe 目标 ≤ 1 MB（实测约 0.91 MB）。
- **不用任何 UI 框架**：托盘是纯 Win32 菜单 + GDI 自绘图标。引入 Avalonia / WinRT 会把
  体积顶到 4 MB+，与「单文件托盘小工具」的目标直接冲突。
- **蓝牙读取走 SetupAPI + CfgMgr32** 读 PnP 设备属性，不依赖 WinRT。
- 关闭反射、固定区域性、各类 BCL 特性开关等一系列 AOT 裁剪选项，取舍与踩坑记录都写在
  `src/BtBattery/BtBattery.csproj` 的注释里。

